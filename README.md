# מסך לובי — יסוד המעלה 9, הוד השרון (v3.3.0)

מערכת תצוגה ללובי בניין מגורים + פאנל ניהול מובנה. פועלת 24/7 ללא מצב לילה.

## ניתוב
- `/` — מסך התצוגה (ברירת מחדל)
- `/#admin` — כניסת מנהל (PIN, ברירת מחדל: `1234` — מומלץ לשנות בהגדרות). **אין קישור גלוי במסך הראשי** — יש להקליד את הכתובת ידנית בדפדפן.
- `/#preview` — תצוגה מקדימה של טיוטות לפני פרסום

## ארכיטקטורה
- **localStorage** — נתונים טקסטואליים (הגדרות, באנרים, הודעות, טיקר, פלייליסט) במודל טיוטה/פרסום (`lobby_*` / `lobby_draft_*`)
- **מיגרציה חד-פעמית** (`src/lib/store.js`, `migrateOnce`) — כשמעדכנים ברירות מחדל של המערכת (למשל הפיכת הודעה לבאנר), מכשירים שכבר פועלים בשטח מתעדכנים אוטומטית ברענון הראשון, בלי צורך בפעולה ידנית
- **IndexedDB** (`lobby-media`) — תמונות (נדחסות אוטומטית) וקבצי אודיו
- קריאות חיצוניות: **Open-Meteo** (מזג אוויר, קואורדינטות הוד השרון) + **מבזקי ynet** דרך פונקציית שרת `api/ynet.js` (מתווך RSS, ללא CORS) + **יוטיוב** (הטמעת iframe לניגון מוזיקת רקע בלולאה, אופציונלי) — כולן עם מטמון/נפילה חלקה
- לוח עברי, חגים, צומות ושבת: חישוב מקומי עם `@hebcal/core` — אין תאריכים מתוחזקים ידנית בקוד
- **ערכות צבע** מתחלפות מפאנל הניהול (`src/lib/themes.js`) — ברירת מחדל "עץ חם" תואמת קיר דמוי-עץ

## תמונות ואיורים
כל האיורים הם SVG מקומי (`src/lib/artwork.jsx`) — ללא מקורות חיצוניים:
- **5 רקעי באנר כלליים**: שקיעה עירונית, גינה פורחת, תבנית גיאומטרית, קיץ ובריכה, ניקיון ותחזוקה. באנר ללא רקע שנבחר ידנית **מתחלף אוטומטית כל 3 ימים** בין כל האיורים (`rotatingArt`)
- **10 רקעי חג** — אחד לכל חג בלוח (`HOLIDAY_ART`)
- **רקע תזכורת דמי ועד** — לוח שנה עם מטבעות ₪ (`VAAD_BG`)
- **אייקוני קטגוריה** לכרטיסי אירועים (מופעים/משפחות/תרבות/קהילה) והודעות דיירים (ועד/תחזוקה/קהילה/חגיגי) — כולל אייקון "מים" עמום ברקע כרטיס האירוע
- טקסט הבאנרים ממוקם **במרכז** בתוך כרטיס קריא (בהיר על איורים, כהה מטושטש על תמונה שהועלתה)

## באנרים אוטומטיים
מחושבים בזמן ריצה ואינם דורשים תחזוקה:
- **באנרי חגים** (`holidayBannerSchedule` ב-`src/lib/hebrew.js`) — 10 חגים (ראש השנה, יום כיפור, סוכות, חנוכה, פורים, פסח, שבועות, יום העצמאות, ט״ו בשבט, ל״ג בעומר). כל באנר מוצג מיום לפני תחילת החג ועד סופו. טאב **"🎉 חגים"** בניהול מציג את כל הלוח לשנה הקרובה עם תאריכי התצוגה, ומתג הפעלה כללי
- **תזכורת דמי ועד** — מופיעה ביום האחרון של כל חודש (חישוב דינמי, מטפל ב-28/29/30/31 יום), עם שם החודש בעברית

## מוזיקת רקע
שני מקורות לבחירה בניהול:
- **יוטיוב**: קישור לוידאו, ניגון בלולאה אינסופית ברקע (ללא תצוגת וידאו)
- **קבצים שהועלו**: MP3 בפלייליסט, מאוחסן ב-IndexedDB
- כשפעילה, מצטרפת שקופיית **"מנגן כעת"** (עם אנימציית אקולייזר) למחזור התצוגה
- נעצרת אוטומטית במהלך שבת וחוזרת לאחר ההבדלה

## מחזור שקופיות ראשי
באנרים פעילים ← באנרי חג פעילים ← אירועי אלומה השבוע ← לוח חגים ומועדים **לחודש הקרוב** (מוסתר לגמרי אם אין חגים בטווח) ← ברכת חג ← תזכורת דמי ועד (ביום האחרון בחודש) ← שבת שלום / סוף שבוע (שישי ביום ומוצ״ש) ← מנגן כעת ← ברכת פתיחה (ברירת מחדל אם אין תוכן אחר)

**מסכים מלאים שתופסים עדיפות:** הודעה דחופה ← שבת (מהדלקת נרות עד ההבדלה — עוצר את כל התוכן והמוזיקה, כולל טיקר ומבזקים).

## תחתית המסך
- **טיקר תחתון** — שורות טקסט מהניהול, מהירות ניתנת לכיוון (`tickerSpeed`)
- **מבזקי ynet** — רצועה נפרדת, מהירות ניתנת לכיוון (`newsSpeed`)
- תג הגרסה בפינה — מוצג בעדינות (שקיפות נמוכה), נלחץ לפתיחת יומן הגרסאות
